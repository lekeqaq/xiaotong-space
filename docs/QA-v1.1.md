# V1.1 数字空间重构验收

日期：2026-10-03，最终复核：2026-10-04。范围包括主页、Writing、Projects、共享页头与主题交互。早期 Lighthouse 分数保留在 QA.md，仅代表 V1，不作为本轮改版分数。

## 实现

- 主页：散落的工作台对象、真实内容入口、照片翻页、便签切换、当地时钟、作品陈列与笔记动态。
- 动效：分层入场、纸张轻浮动、轨道节点、实验连线、Dock 悬停反馈、滚动显现。没有新增动画依赖。
- Projects：山野/海边场景淡入切换、票据入场、路线流动；倾听/思考/回应三种视觉状态；项目与笔记来源切换和真实页面链接。
- 主题：首次跟随系统，按钮直接切换浅/深色并保存偏好；View Transition 从按钮中心展开；不支持的浏览器使用 CSS 颜色过渡；减少动态效果时直接切换。
- Writing：一体化搜索焦点、分类下划线、直接点选标签、笔记列表、空状态和重置。

## 验证

- `pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm test` 通过，现有 23 项生产 SSR/SEO/内容/404 测试通过。
- 浏览器验证照片翻页与便签切换；动画暂停后，卡片持续动画、轨道节点、连线动画均为 paused，恢复可用。
- 观察到主题切换中间状态的圆形裁剪；正向与反向切换成功，动画期间的重复点击不叠加，刷新后主题保留。
- 旅行场景正确更新图片、标题、票据与选中状态；数字人三个阶段正确切换；知识来源切换后显示实际文章，链接可打开正文。
- 搜索 RAG 返回 1 篇，带首尾空格的 webrtc 返回 1 篇；标签与分类组合可产生空状态；重置恢复 3 篇；Escape 清除关键词。
- 手机使用独立排版；修正平板端作品页装饰卡片导致的横向溢出。
- 修正手机端动效按钮图标被文字隐藏规则误伤的问题，验证图标正常显示。
- 在独立生产浏览器标签中验证主页 → Projects → 内容详情 → Writing 的客户端导航和交互，未发现 error / warn。
- 减少动态效果与旧浏览器主题回退通过代码检查；未修改用户系统设置来模拟这些环境。
